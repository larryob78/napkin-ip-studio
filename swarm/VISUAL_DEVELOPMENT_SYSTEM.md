# Visual Development System

Defines a consistent visual pipeline for all Tencent pitch decks.

## Roles
- Executive Creative Director
- Visual Showrunner
- Art Director
- Cinematographer
- Character Supervisor
- Environment Designer
- Image Producer
- Quality Control

## Deck Bible
- 16:9 landscape full-bleed images
- Premium photoreal cinematic style
- Consistent character identity across all pages
- Consistent world-building, lighting, palette and lens language
- No text, logos, watermarks or AI artifacts in images.

## Deliverables
- One hero image per page
- Supporting environmental and character art
- Image prompt library
- Page-by-page shot list
- Visual continuity checklist

## Workflow
1. Approve visual thesis.
2. Lock character references.
3. Lock environment references.
4. Generate hero images.
5. Perform quality review.
6. Assemble PowerPoint with full-bleed artwork.
7. Final executive review before export.
