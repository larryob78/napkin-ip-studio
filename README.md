# Napkin IP Studio

A reusable AI-native development system for building premium episodic intellectual property.

## Flagship projects

- Baby Demon
- The Last Boy on Earth

Both projects use the same controlled development system while preserving distinct tone, canon, visual language and audience promise.

## System architecture

1. A reusable IP-development skill defines the process.
2. A controlled swarm divides work into specialist roles.
3. Canon files prevent contradiction.
4. Small task packets are created, reviewed, revised and approved.
5. Only approved material enters the living bibles.
6. Git records every decision and version.

## Core outputs per project

- Story Bible
- Character Bible
- Episode Bible
- World Bible
- Brand Bible
- Art Direction Bible
- Production Bible
- Two-minute proof-of-concept brief

## Season format

- 10 episodes
- Approximately 15 minutes per episode
- Approximately 150 minutes per season

## Quality principle

Character before spectacle. Emotional truth before mythology. Cause and effect before coincidence. Every episode must be entertaining on its own and move the season forward.
