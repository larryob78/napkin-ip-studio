# 1. Operating rule

Do not generate the project as disconnected hero images.

Every downstream frame must inherit approved upstream references. A beautiful image that breaks identity, scale, costume, anatomy, geography or prop continuity is a failed production asset.

Approval of a visual reference locks only production-visible features. It does **not** automatically lock unresolved story canon.

Protected unresolved decisions include:

- boy's final name, exact age, ethnicity, carers and full biography
- exact duration of his isolation
- final signature personal object
- final alien names and final species anatomy until separately approved
- Memory Ark as final mythology
- off-world human communities as final canon
- exact cause of humanity's disappearance
- identity of the approaching force

---

# 2. Status vocabulary

- **BLOCKED** — required upstream reference is not approved.
- **READY** — all required inputs exist; generation may begin.
- **WIP** — candidates exist but are not continuity authority.
- **REVIEW** — narrowed candidate awaiting approval.
- **APPROVED** — continuity authority for downstream production.
- **REJECTED** — retained only as learning; never reused as a seed/reference.
- **PROVISIONAL** — may be approved for production while an underlying story choice remains unresolved.

No downstream item may inherit from WIP, REVIEW or REJECTED references.

# 9. Approval metadata

Every approved visual asset should have a small Markdown or JSON sidecar recording:

- asset ID
- current filename
- status and version
- approval date
- approving creative owner
- exact source brief version
- generator/tool/model used, if applicable
- seed/reference IDs where reproducible
- inherited approved references
- canon facts intentionally **not** locked by the image
- known limitations
- downstream shots/pages that inherit it

This metadata is mandatory for continuity-critical refs REF01–REF14.

# 10. Daily production review

At any review point, answer these six questions in order:

1. Which READY item has the highest number of downstream dependencies?
2. Which REVIEW item can be approved or rejected now rather than spawning more variants?
3. Has any new image introduced an unapproved story fact?
4. Has any approved reference drifted in a downstream frame?
5. Are we generating duplicate exploration instead of closing a gate?
6. What single approval today unlocks the most tomorrow?
