# 1. Core production rule

These are not eighteen independent image prompts.

Every frame must inherit approved references from `PROOF_CONTINUITY_PACK.md`. If a required reference is not yet **APPROVED**, the frame remains **BLOCKED** or may be generated only as a non-continuity composition study.

The purpose of the storyboard is to prove:

- spatial continuity
- eyelines
- emotional progression
- screen direction
- prop logic
- lens discipline
- hand contact
- scale
- lighting continuity
- edit rhythm

The storyboard is successful only if the eighteen frames read as one short film.

---

# 2. Global image language

**Format:** premium episodic animation with photographic credibility.  
**Aspect:** 16:9 landscape.  
**Camera:** physical lens behaviour, restrained movement, child-height visual logic once on Earth.  
**Earth:** wet, green, ecologically alive, recognisably Dublin, never generic ruin-porn.  
**Alien technology:** tactile, layered, culturally specific, no generic floating holograms.  
**Colour:** wet greens, slate blue, pale stone, aged brick, mineral grey. Warm gold/amber only for memory, invitation, reply and moral choice.  
**Performance:** small readable changes in face, posture and distance. Avoid heroic poses.

## Negative prompt / rejection language for all frames

Reject:

- generic grey aliens
- saucer spacecraft
- neon cyberpunk UI
- tactical apocalypse styling
- superhero poses
- sentimental glow
- fantasy magic light
- impossible hands
- inconsistent eye-lines
- mismatched character scale
- duplicated faces or props
- foliage applied evenly as decoration
- dry surfaces during active rain
- water that behaves like a static mirror
- arbitrary camera angles unsupported by the floor plan
- images that reveal unresolved mythology

# 9. Storyboard approval checklist

A shot can move to **APPROVED** only when all applicable tests pass:

- correct reference versions inherited
- exact character face continuity
- exact wardrobe continuity
- exact alien anatomy continuity
- approved relative scale
- physically correct hand/object contact
- eyelines intersect correctly
- concourse floor plan preserved
- rain/water/material logic preserved
- established screen direction preserved
- prop states match adjacent shots
- emotional state matches sequence stage
- no unresolved mythology is accidentally revealed
- no generic sci-fi or apocalypse shorthand introduced
- frame supports its edit duration and story purpose

# 10. Motion handoff note

Once all eighteen keyframes are approved, create a motion handoff per shot containing:

1. approved keyframe
2. start pose / end pose
3. camera movement allowance
4. character movement allowance
5. environmental motion allowance
6. forbidden changes
7. expected duration
8. sound cue
9. previous-shot continuity dependency
10. next-shot continuity dependency

Do not ask a motion model to redesign any approved visual element.

The motion task is to animate continuity, not create new continuity.
